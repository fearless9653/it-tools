### 普通字符

| 表达式                  | 描述                         |
| :---------------------- | :--------------------------- |
| `.` 或 `[^\n\r]`        | 除换行符或回车符外的任意字符 |
| `[A-Za-z]`              | 字母                         |
| `[a-z]`                 | 小写字母                     |
| `[A-Z]`                 | 大写字母                     |
| `\d` 或 `[0-9]`         | 数字                         |
| `\D` 或 `[^0-9]`        | 非数字                       |
| `_`                     | 下划线                       |
| `\w` 或 `[A-Za-z0-9_]`  | 字母、数字或下划线           |
| `\W` 或 `[^A-Za-z0-9_]` | `\w` 的反向                  |
| `\S`                    | `\s` 的反向                  |

### 空白字符

| 表达式 | 描述                         |
| :----- | :--------------------------- |
| ` `    | 空格                         |
| `\t`   | 制表符                       |
| `\n`   | 换行符                       |
| `\r`   | 回车符                       |
| `\s`   | 空格、制表符、换行符或回车符 |

### 字符集

| 表达式   | 描述                         |
| :------- | :--------------------------- |
| `[xyz]`  | `x`、`y` 或 `z` 中的任意一个 |
| `[^xyz]` | 非 `x`、`y` 或 `z` 的字符    |
| `[1-3]`  | `1`、`2` 或 `3` 中的任意一个 |
| `[^1-3]` | 非 `1`、`2` 或 `3` 的字符    |

- 将字符集视为方括号内单个字符的 `OR` 操作。
- 在开头的 `[` 后使用 `^` 来"否定"字符集。
- 在字符集中，`.` 表示字面意思的句号。

### 需要转义的字符

#### 在字符集外部

| 表达式 | 描述               |
| :----- | :----------------- |
| `\.`   | 句号               |
| `\^`   | 插入符号（脱字符） |
| `\$`   | 美元符号           |
| `\|`   | 竖线               |
| `\\`   | 反斜杠             |
| `\/`   | 正斜杠             |
| `\(`   | 开括号             |
| `\)`   | 闭括号             |
| `\[`   | 开方括号           |
| `\]`   | 闭方括号           |
| `\{`   | 开花括号           |
| `\}`   | 闭花括号           |

#### 在字符集内部

| 表达式 | 描述     |
| :----- | :------- |
| `\\`   | 反斜杠   |
| `\]`   | 闭方括号 |

- `^` 只有在字符集开头的 `[` 之后出现时才需要转义。
- `-` 只有在两个字母或两个数字之间时才需要转义。

### 量词

| 表达式  | 描述                   |
| :------ | :--------------------- |
| `{2}`   | 精确匹配2次            |
| `{2,}`  | 至少匹配2次            |
| `{2,7}` | 至少匹配2次但不超过7次 |
| `*`     | 0次或更多次            |
| `+`     | 1次或更多次            |
| `?`     | 精确匹配0次或1次       |

- 量词放在要量化的表达式之后。

### 边界

| 表达式 | 描述       |
| :----- | :--------- |
| `^`    | 字符串开头 |
| `$`    | 字符串结尾 |
| `\b`   | 单词边界   |

- 单词边界匹配的工作方式：
  - 如果字符串开头的第一个字符是 `\w`，则在字符串开头匹配。
  - 在字符串中两个相邻字符之间，如果第一个字符是 `\w`，第二个字符是 `\W`，则匹配。
  - 如果字符串结尾的最后一个字符是 `\w`，则在字符串结尾匹配。

### 匹配

| 表达式        | 描述                        |
| :------------ | :-------------------------- |
| `foo\|bar`    | 匹配 `foo` 或 `bar`         |
| `foo(?=bar)`  | 匹配后面跟着 `bar` 的 `foo` |
| `foo(?!bar)`  | 匹配后面不跟 `bar` 的 `foo` |
| `(?<=bar)foo` | 匹配前面有 `bar` 的 `foo`   |
| `(?<!bar)foo` | 匹配前面没有 `bar` 的 `foo` |

### 分组和捕获

| 表达式       | 描述                                             |
| :----------- | :----------------------------------------------- |
| `(foo)`      | 捕获组；匹配并捕获 `foo`                         |
| `(?:foo)`    | 非捕获组；匹配 `foo` 但不捕获 `foo`              |
| `(foo)bar\1` | `\1` 是对第1个捕获组的反向引用；匹配 `foobarfoo` |

- 捕获组只在以下方法中相关：
  - `string.match(regexp)`
  - `string.matchAll(regexp)`
  - `string.replace(regexp, callback)`
- `\N` 是对第 `N` 个捕获组的反向引用。捕获组从1开始编号。
